Hide Menus Per User

Total Control over User Access

Securely block selected modules on a per-user basis. Present empty lists, completely hide creation/editing buttons, and strictly restrict creation directly at the ORM level.

Compatible with Odoo 16.0 · 17.0 · 18.0 · 19.0

1. Configure Blocked Modules via User Settings

Open any User profile and find the new "Blocked Modules" tab. This native-looking integration gives administrators a straightforward way to manage permissions per user.

2. Select Root Menus to Restrict

Pick the main root menus (Sales, Purchase, Inventory, Approvals...) you want to restrict for this user. Selecting a root menu recursively restricts access to every model exclusive to that subtree.

3. View the Action-Restricted, Empty Result

From the restricted user's point of view, the module remains accessible but is fully emptied. Crucially, no actions are allowed: New, Edit, Delete, Duplicate, Import, or Export buttons are removed. Records are hidden, and ORM-level protections enforce the rule even via API.

Key Features

  • Per-user configuration: block modules for one user without touching groups or roles.
  • Empty lists: the user sees the standard empty state inside the blocked module.
  • Buttons removed: New, Edit, Delete, Duplicate, Import (Upload) and Export disappear from list, kanban and form views.
  • ORM-level enforcement: direct API calls to create() on a blocked model raise AccessError.
  • Smart scope: only models exclusive to the blocked menu are affected. Shared models (e.g. res.partner, product.template) keep working everywhere else.
  • Framework-safe: ir.*, base.* and core res.* models (users, groups, company...) are never blocked, even if listed under a hidden menu.

Installation

  1. Drop the module in your addons path (e.g. /mnt/extra-addons/hide_menus_per_user).
  2. Restart the Odoo server.
  3. Activate developer mode: Settings → Developer Tools → Activate the developer mode.
  4. Go to Apps, click Update Apps List, search for Hide Menus per User (clear the "Apps" filter, the module is in the Tools category) and install.

Usage

  1. Open Settings → Users & Companies → Users and pick the user you want to configure.
  2. Switch to the Blocked Modules tab (added by this module).
  3. Click Add a line and select one or more root menus (e.g. Sales, Purchase, Inventory). Only top-level menus are listed.
  4. Save the user.
  5. The change applies on the user's next page reload — no logout required.

FAQ

Why is the menu still visible? I expected it to be hidden.
By design. The user can navigate to the module, but every list will be empty and there will be no buttons to create, edit or export anything. If you also want the menu hidden, use security groups instead.

Will the user still be able to read existing records by typing a record URL?
Reading a single record is still controlled by the standard Odoo security layer (groups, record rules). This module focuses on listing, creating and editing. To fully forbid read, also remove the user from the relevant security groups.

Does the change require a logout?
No, a page reload is enough.

Does it impact performance?
Negligible. The set of blocked models is cached per user with ormcache; the override only adds a frozenset membership check on each _search call when the user has at least one blocked module configured.

Can I block submenus only?
No. Blocking is by root menu (and applies to all the models exclusive to that subtree).
